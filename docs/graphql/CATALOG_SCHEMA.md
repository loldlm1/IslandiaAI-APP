# GraphQL Schema Catalog

This reference summarizes the current GraphQL surface captured in [`frontend/docs/graphql/schema.graphql`](../docs/graphql/schema.graphql).

> **Maintenance tip:** Refresh this catalog whenever `frontend/docs/graphql/schema.graphql` changes so the quick reference stays in sync with the schema snapshot.

## Queries

| Field | Description |
| --- | --- |
| `customer` | Find a customer by their globally unique ID. |
| `customers` | List all customers managed by the platform. |
| `invoice` | Find an invoice by its globally unique ID. |
| `invoiceLineItem` | Find an invoice line item by its globally unique ID. |
| `invoiceLineItems` | List all invoice line items across invoices. |
| `invoices` | List all invoices generated in the system. |
| `magicInvoiceSubmission` | Find a magic invoice submission by its globally unique ID. |
| `magicInvoiceSubmissions` | List all magic invoice submissions. |
| `node` | Fetches an object given its ID. |
| `nodes` | Fetches a list of objects given a list of IDs. |
| `order` | Find an order by its globally unique ID. |
| `orders` | List all orders created in the system. |
| `product` | Find a product by its globally unique ID. |
| `productRequest` | Find a product request by its globally unique ID. |
| `productRequests` | List all product requests. |
| `products` | List products across all suppliers. |
| `supplier` | Find a supplier by their globally unique ID. |
| `suppliers` | List all suppliers managed within the platform. |
| `user` | Find a user by their globally unique ID. |
| `users` | List all users in the system. |
| `viewer` | The currently authenticated user. |

## Mutations

| Field | Description |
| --- | --- |
| `createOrder` | Create an order scoped to the authenticated user. |
| `signIn` | Authenticate a user with email and password credentials. |
| `signOut` | Destroy the session for the current user. |
| `signUp` | Register a new user and start a signed-in session. |
| `submitMagicInvoice` | Submit documents to the magic invoice ingestion pipeline. |
| `updateOrderStatus` | Update the status of an existing order owned by the current user. |

## Subscriptions

_No subscription fields are defined in the current schema._

## Scalars

| Name | Description |
| --- | --- |
| `BigInt` | Represents non-fractional signed whole numeric values. Since the value may exceed the size of a 32-bit integer, it's encoded as a string. |
| `ISO8601Date` | An ISO 8601-encoded date. |
| `ISO8601DateTime` | An ISO 8601-encoded datetime. |
| `JSON` | Represents untyped JSON. |
| `Upload` | Represents a file upload following the GraphQL multipart request specification. |
